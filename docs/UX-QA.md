## Что исправлено

- Черновик настроек и открытая категория сохраняются при переходе через нижнее меню. Скрытые формы недоступны с клавиатуры.
- Повторное редактирование только что сохранённого факта не создаёт ложного конфликта. Настоящее параллельное изменение всё ещё блокирует сохранение; локальную правку можно отменить.
- При ошибке записи настройки видна понятная ошибка, остаётся последнее сохранённое значение, повтор доступен. При медленной записи виден статус; повторные изменения временно недоступны.
- Убрана дублирующая подсказка записанных сцен. Название памяти, путь к импорту и описание очереди проверки согласованы с действующим меню и режимом подтверждения.
- Обновлены сценарии старых путей и скрытых технических данных. Проверки редактирования, фокуса, отмены, редактирования персонажа, доступности и сохранности данных сохранены.

## Как повторить

Нужен полный Git checkout с `tests/` и установленными зависимостями/браузерами Playwright. Использован Node **24.19.0**, Vitest **5.0.3**. Системный Node20 не поддерживается установленным Vitest; он давал ошибки WebCrypto в jsdom. В командах ниже `node` должен указывать на поддерживаемый runtime.

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vitest/vitest.mjs run --maxWorkers=1 --reporter=dot
node node_modules/wxt/bin/wxt.mjs build
node node_modules/@playwright/test/cli.js test --config playwright.ux.config.ts --grep-invert '280 MiB'
node node_modules/@playwright/test/cli.js test --config playwright.ux.config.ts --grep '280 MiB' --workers=1
```

`playwright.ux.config.ts` содержит явный перечень UX-сценариев, запускает отдельный сервер4175 на том же Node, не переиспользует чужой предпросмотр. Общий предел2 workers, Firefox —1: установленный test runtime давал ошибку параллельного закрытия контекстов. Большой экспорт запускается отдельно, чтобы не создавать конкуренцию за память. Существующий общий E2E-конфиг сохранён.

- UI проверяется в Edge/Chromium и Firefox. Установка MV3 и сетевой перехват тестируются в отдельном Edge, не в личной установленной копии.
- Brave на этой машине отсутствует; соответствующие существующие сценарии явно пропускаются. Edge-only сценарии пропускаются в проекте Firefox; большой fixture запускается один раз.

- Не запускался весь несвязанный E2E-набор всех RP-этапов. Весь unit-набор проверяется отдельно. Старые5 todo остаются todo.

- Автоматическая проверка запретила удаление созданных временных профилей в `test-results-ux267*` без пояснения причины. Профили и отчёты оставлены локально в игнорируемых каталогах; в архивы они не входят. Собственный ручной сервер4176/вкладка закрыты, прежний4173 не трогали.
