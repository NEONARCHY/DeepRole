# RP263: проверка локального поиска по смыслу

Это отдельный исследовательский стенд. Он не подключён к отправке сообщений, не меняет память мира и не обновляет установленное расширение.

## Зачем он нужен

Одинаковое событие можно описать разными словами: в источнике «подарила медальон», в вопросе «памятное украшение именинницы». Совпадения слов бывает недостаточно. Проверяем, помогает ли дополнительный поиск по смыслу находить целые исходные записи, сохраняя различия между людьми и событиями.

Пользователь 14 октября 2026 отдельно разрешил скачать локальную модель и зависимости для эксперимента. Личный лор не используется и не отправляется новому сервису. Скачивание не означает согласие на последующую установку модели всем пользователям расширения.

## Зафиксированные данные и правила

- 40 ранее опубликованных примеров RP262 и 24 новых RU/EN примера. Новые предметы и события: шарф, резная птица, фотоаппарат, условное поручение, снежная буря и травма.
- Все ожидаемые источники размечены вручную до запуска модели. Набор, текущий выбор, ранжирование и SHA256 закреплены в `tests/fixtures/story-search-baseline.json`.
- К исходным событиям добавлены 96 поздних обсуждений в первом наборе и 72 во втором. Старая открытая версия возвращённого фотоаппарата удаляется существующей компактацией до поиска.
- Сравниваются фактический контекст компилятора, нынешние первые 8 лексических кандидатов, первые 8 по косинусной близости и фиксированное объединение рангов `1/(60+rank)` с равными весами. Сначала сравниваем кандидатов одинаковой ёмкости.
- Для распознанного запроса о владельце и неоднозначного имени объединение сохраняет прежний выбор целиком. Сходство текстов не назначает владельца предмета, обещания или секрета.
- Отдельно считаются полные нужные наборы, пропущенные источники, неверная первая позиция и изменение контекста неизвестных/неоднозначных запросов. Контроль с пустым ожидаемым набором не получает фиктивный балл за «всё найдено».

Модель видит только `query: …` и `passage: …` с текстом факта и названием поручения. Эталон, ключи задач, роли и непрозрачные идентификаторы источников не добавляются к текстам. Поисковый запрос может содержать существующую помощь с известными именами; исходный текст пользователя остаётся прежним. 424 различных входа переиспользуются по точному хешу.

**Первые восемь кандидатов ещё не являются готовым запросом DeepSeek.** В этой итерации не измеряются допуск в общий бюджет, качество ответа модели, поведение личного мира и браузерная скорость. Полнота кандидатов не доказывает правильное разрешение местоимений или разрешение на действие.

## Модель и загрузка

Выбран `Xenova/multilingual-e5-small`, revision `ae61bf0193ce3851dc8a45147e459b04ed783d8a`, q8, mean pooling, 384 измерения. Пять необходимых файлов занимают **135 392 183 байта** без среды запуска. Каждому файлу проверяются длина и SHA256 либо исходный Git blob hash. Дополнительные веса репозитория не скачиваются.

Среда `@huggingface/transformers@3.8.1` установлена отдельно в игнорируемом `private-assets/semantic-runtime`. Установленные зависимости и веса не входят в сборки и ZIP; в sources сохранены только шаблон и отдельный lockfile в `scripts/story-search-runtime`, чтобы закрепить также транзитивные версии. Веса находятся в `private-assets/semantic-models`. Для повторения потребуется полный Git checkout с тестовыми фикстурами; опубликованный source ZIP по прежним правилам не содержит тесты.

Префиксы, pooling и нормализация соответствуют [карточке multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small) и [официальному FeatureExtractionPipeline](https://huggingface.co/docs/transformers.js/v3.8.1/en/api/pipelines#module_pipelines.FeatureExtractionPipeline). [Закреплённые файлы ONNX-модели](https://huggingface.co/Xenova/multilingual-e5-small/tree/ae61bf0193ce3851dc8a45147e459b04ed783d8a) задают размер/контрольные суммы. Абсолютное значение близости не используется как универсальный порог уверенности.

## Повторение

Все команды — из корня Git checkout. `node` должен быть доступен в PATH. `--plan` и unit-тесты ничего не скачивают.

```powershell
node scripts/story-search-benchmark.mjs --plan
node scripts/story-search-benchmark.mjs --export private-assets/rp263-inputs.json
```

После согласования скачивания: установить закреплённую библиотеку в отдельную папку, затем разрешить загрузку ровно пяти файлов явным флагом. Установка не должна изменять основной `package.json`/lockfile.

```powershell
New-Item -ItemType Directory -Force private-assets/semantic-runtime
Copy-Item scripts/story-search-runtime/package.json private-assets/semantic-runtime/package.json
Copy-Item scripts/story-search-runtime/pnpm-lock.yaml private-assets/semantic-runtime/pnpm-lock.yaml
pnpm --dir private-assets/semantic-runtime install --frozen-lockfile --ignore-scripts
node scripts/story-search-benchmark.mjs --encode --runtime private-assets/semantic-runtime/node_modules/@huggingface/transformers/dist/transformers.node.mjs --model-dir private-assets/semantic-models --download-model --out private-assets/rp263-vectors.json
```

По умолчанию разрешены только локальные файлы. Отсутствующая модель, неверный хеш, другая версия/размерность, старый набор, пропущенные, лишние, повторные или некорректные векторы дают явную ошибку. Отчёт создаётся рядом с артефактом в JSON и Markdown. `--freeze` предназначен для нового явно проверенного эксперимента и не перезаписывает существующий эталон.

Повторный холодный запуск с уже скачанными файлами и запрещёнными сетевыми вызовами Node:

```powershell
node scripts/story-search-offline.mjs --encode --runtime private-assets/semantic-runtime/node_modules/@huggingface/transformers/dist/transformers.node.mjs --model-dir private-assets/semantic-models --out private-assets/rp263-offline.json
```

Повтор той же команды использует проверенный кэш векторов. Это отдельный замер: чтение готовых векторов не равно скорости вычисления нового запроса. Проба блокирует `fetch`, HTTP/HTTPS и подключения сокетов Node; физическое отключение сети и браузерный режим этим не проверяются.

## Результат и следующий шаг

**Этот вариант не внедряем в игру:** простое объединение рангов ухудшило поиск. Все параметры сравнения были зафиксированы до просмотра holdout; после результата набор и веса не подгонялись.

| Набор с известными нужными источниками | Запросов | В контексте сейчас | Лексические top8 | Смысловые top8 | Объединение |
| --- | ---: | ---: | ---: | ---: | ---: |
| Исходный набор RP262 | 32 | 25 | 26 | 14 | 21 |
| Новые примеры | 18 | 15 | 16 | 14 | 14 |
| Всего | 50 | 40 | 42 | 28 | 35 |

Ещё 14 запросов — контроль неизвестного предмета/события, совпадающего прозвища или заменённого человека. Объединение изменило прежний состав/порядок в 8 из 14 случаев. Это отдельный сигнал риска; он не доказывает, что DeepSeek выдумал событие. Прямые запросы теряют 2 из 20 полных наборов при объединении, хотя текущие лексические top8 находят все 20. Из 20 перефразов полные наборы: лексический поиск 16, смысловой 14, объединение 14; неверная первая позиция — 6/7/7 соответственно. Для 10 общих ссылок с несколькими источниками полнота — 6/3/3.

В отдельных русских примерах модель добавила нужный источник о спасении из воды или одежде Севера. В других случаях поздние обсуждения тех же тем вытеснили исходное событие. Например, в английском запросе о серебряном медальоне близость к одному позднему обсуждению оказалась 0,812, к исходному подарку — 0,780. Простое сходство не отличает уверенно «обсуждали подарок» от «подарили». Это наблюдение на выбранных данных и модели; оно не означает бесполезность всех методов смыслового поиска.

Подробные группы, каждый случай, модель, хеши, метод и аппаратные условия сохранены в [машинном отчёте](benchmarks/rp263-search-results.json). Ранжирование текущего компилятора и порядок уже собранного контекста различаются; для сравнения первой позиции используются именно лексические кандидаты, а не порядок компилятора.

### Скорость и размер на этом ПК

Intel Core i5-10400, Windows x64, Node 24.19.0, два потока инференса:

- Первый запуск после скачивания: загрузка среды/модели 1,28 с, вычисление 424 различных входов 5,37 с, медиана одного входа 12,3 мс, p95 23,0 мс.
- Повторное вычисление с запрещёнными сетевыми вызовами Node: загрузка 0,92 с, 424 входа за 4,16 с, медиана 9,5 мс, p95 13,6 мс; ноль попыток сетевого обращения. Векторы точно совпали с первым запуском.
- Проверенный кэш 424 готовых векторов прочитан за 18,7 мс; это не измерение нового запроса. Отдельный проход оценки — около 46–53 мс. Полный CLI включает компиляцию фикстур Vite и занимает существенно дольше.
- Веса/токенизатор: 135 392 183 байта; установленная папка дополнительных зависимостей: 391 572 893 байта логического размера файлов. Глобальное хранилище pnpm сюда не включено; жёсткие ссылки могут отличать физический расход диска. Эти файлы не добавлены в поставку расширения.
- Максимальный RSS всего процесса при повторном вычислении — около 816 МБ, включая подготовку Vite/фикстур. Это не оценка памяти браузера или только модели.

Повторная обработка по одному входу дала идентичные векторы. Дополнительная проверка обработки пачкой показала численные отличия до 0,0145 у q8 при другом padding; измеренный стенд последовательно обрабатывает входы по одному. Ни один вход не превышает 512 токенов; максимум — 46, молчаливого обрезания нет.

**Продолжение RP264 выполнено:** [разнообразие кандидатов и защита исходных доказательств](SEARCH-DIVERSITY.md). Два дополнительных новых набора поэтапно зафиксированы до своих запусков, проверен целый запрос. Защита устранила потери прежних источников, но второй независимый набор не показал нового выигрыша14/20→14/20; новый вариант также остаётся отдельным стендом. Текущий рабочий алгоритм RP262 сохранён. Следующая задача и пределы — в актуальной передаче; просмотренные наборы не считать новыми и не подбирать по ним параметры до красивого результата. RP-05 открыт.

## English

An isolated read-only Node experiment compares current compiled selection, lexical top8, dense top8 and fixed equal-weight reciprocal-rank fusion. The 40-case development corpus plus 24 independently authored bilingual holdout cases were frozen before model evaluation. Only synthetic text is encoded. Existing owner/ambiguous-identity selections remain protected; no owner, object identity, knowledge transfer or consent is inferred from similarity. Whole prompt admission and live-model quality are outside this candidate-only comparison.

The user approved this local experiment download. The pinned q8 multilingual E5 model and tokenizer require 135,392,183 bytes, excluding the optional runtime, and remain outside the production bundle. Default operation is local-only; a separate Node network-blocking probe checks repeated inference. A vector-cache hit is reported separately from actual inference. No production rollout or extension reload follows automatically.
