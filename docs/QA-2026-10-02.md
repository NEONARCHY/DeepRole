# Проверка DeepRole · 2 октября 2026

## Что действительно проверено на DeepSeek

В отдельной нейтральной истории про обсерваторию, без личного лора:

| Проверка | Реальный результат |
| --- | --- |
| «Всегда»: код фонаря записан только в DeepRole | DeepSeek ответил **ЯНТАРЬ-47**, хотя вопрос не содержал кода. |
| «Вручную»: секрет конверта ещё не выбран | Ответ **«неизвестно»**. |
| Тот же секрет после ручного включения | Ответ **КЕДР-83**. |
| «Автоподбор»: вопрос о полярном спектрометре | В контекст добавилась нужная запись; ответ **ЛИРА-62**. |
| Обновление лора | Видимый запрос, ответ модели, окно с двумя предложениями. Без автоматической записи. |
| Выбрать одно предложение из двух | Обновилась одна существующая запись, без дубликата; её режим сохранился. |
| Отменить последнее сохранение | Исходный текст восстановился. |
| Другой чат | Ручной секрет туда не перенёсся; модель ответила «неизвестно». |

Модель также предложила сделать вывод о характере смотрителя по нескольким действиям. Это предложение было отклонено: наличие флажков проверки действительно нужно.

## Что исправлено

- Замена технического JSON склеивала текст и уничтожала разметку ответа. Теперь меняется только сам блок данных; абзацы, ссылки и оформление вокруг сохраняются.
- В окне предложений нельзя было выбрать режим новой записи. Теперь доступны те же три режима, что в остальном расширении. Для изменения существующей записи явно указан сохраняемый режим.
- Пустое название приводило к непонятной ошибке сохранения. Теперь причина видна до отправки; во время сохранения поля защищены от повторных правок.
- Окно проверки содержало вторую шапку и действия другого экрана. Они убраны на время редактирования; одна прокрутка, заметное сохранение, спокойные второстепенные кнопки.
- Новые нейтральные карточки с явным возрастом персонажа не распознавались. Добавлено осторожное распознавание начального утверждения о возрасте и имени на RU/EN; случайный возраст внутри сцены не меняет её раздел. Обсерватория распознаётся как место.
- Обзор карты рассчитывался только по первому кольцу. Теперь учитываются и внешние карточки, но сохраняется минимальный удобный масштаб. Большую карту всё ещё нужно перемещать; вариант с чрезмерным уменьшением отклонён после тестов перекрытия кнопок.

Тексты, события и возрасты пользовательского лора не переписывались. Распознавание меняет организацию карты, а не алгоритм отправки памяти.

## Автоматические проверки

- TypeScript без ошибок; **295 unit/integration тестов**.
- Финальный полный последовательный E2E после всех правок кода: **191 прошёл**, **21 ожидаемый пропуск** установленного Chrome-runtime в Firefox, **0 ошибок** (6,6 минуты).
- Покрыты импорт/резервные копии/сейф, карта/список/исходящий контекст, профили и миры, split-screen, история правок, ошибки и отмена запросов, смена чатов, защита черновика, RU/EN и узкие панели.
- Промежуточные прогоны были неуспешны: в параллельном — сбои запуска браузеров и старое ожидание текста; эксперимент с чрезмерным уменьшением карты дал 6 ошибок Chrome. Его отклонили и повторили весь прогон после исправления. Только итоговый прогон считается зелёным.

## Ограничения этой проверки

- Встроенное меню расширения при управлении браузером становится пустым; пользователь подтвердил, что самостоятельно оно открывается нормально. Поэтому карта, импорт и сейф проверены в тестовой среде, но не объявляются полностью проверенными на личном аккаунте.
- После перезапуска Brave прежняя ссылка тестового чата вернула «Чат не найден». Причина не установлена; без доказательств это не отнесено к ошибке DeepRole. Повторная проверка сохранения исключения после перезапуска на живом сайте не завершена.
- Три созданные записи имеют префикс **QA •**. Пользователь решил удалить их позже самостоятельно. Чужие записи не удалялись.
- Сборки и ZIP пересозданы. Это не равно подтверждённой перезагрузке установленной копии. Совместимость со всеми сторонними расширениями, любыми JSON и будущими изменениями DeepSeek не гарантируется.
