## Независимые истории

Обсерватория и театр; Ада, Борис, Вера; RU/EN. Девять содержательных записей:
два обещания осмотра с разными исполнителями и условиями, частичное восстановление
питания, отозванный допуск, условный возврат, завершённая доставка, отдельный ещё
не выполненный осмотр, новое требование проверки крепления и неподтверждённое
мнение о владельце. После них 80 либо 400 отдельных явно пустых разговоров.
Каждая запись имеет собственный сохранённый source и историческую роль.

## Ожидаемое

- Вопрос и одно действие по первому предмету: источники 0,1,2,7,8 целиком.
- Два действия по первому и второму: дополнительно 3,4.
- Три действия: все девять источников; обратный порядок второго/третьего: 3–6.
- Полный text, quote, task, claim, роль и source не меняются. Доставка не закрывает
  осмотр, вера в владельца остаётся belief, новый пункт не считается пустым повтором.
- При достаточном бюджете 6000 явно пустые повторы не вытесняют эти источники.
- Неизвестный предмет и неоднозначное местоимение не получают complete coverage.
- Холодный индекс, тёплый индекс после чтения новых копий из базы и индекс после
  закрытия/открытия базы дают один результат. Сохранённое состояние не меняется.

56 query/size/locale/plot случаев, каждый проверяется в трёх состояниях индекса.
40 положительных проверок выборки и 16 отрицательных проверок уверенности.
Хранилище: настоящие repository/Dexie поверх изолированного fake IndexedDB,
не личное расширение и не ответы живой модели. Это отдельно от RP334.

## Прозрачное усиление harness после первого run

Замороженный файл выше и его gold не менялись. После обнаружения production
пропуска и отдельного отказа runtime на неполном стенде добавлен адаптер
`story-persisted-evidence.ts`: production-валидируемая история source revisions,
receipts и checkpoint продолжения. Роли выводятся из той же прозаической цитаты
через `bindStoryRoles`; событиям без говорящего не приписывается speaker.
Golden source indices, порядок, текст и ожидаемые факты прежние. Дополнительные
18 fallback controls и один startup graph control проверяют guards, а не меняют
gold нового набора. Итоговые 168 измерений повторяются на усиленном harness.
