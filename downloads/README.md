# Скачать DeepRole

Версия 0.1.0 — ранняя сборка для установки вручную.

| Браузер | Файл | Как установить |
| --- | --- | --- |
| Chrome, Brave, Edge | [Скачать ZIP](deeprole-0.1.0-chrome.zip?raw=true) | Распаковать и загрузить папку как расширение. |
| Firefox | [Скачать ZIP](deeprole-0.1.0-firefox.zip?raw=true) | Распаковать и загрузить `manifest.json` как временное дополнение. После перезапуска Firefox его нужно загрузить снова. |

Подробные шаги для обоих браузеров — в [инструкции по установке](../INSTALL.md). Исходный код с тестами находится в [репозитории](../README.md); отдельный [архив исходников](deeprole-0.1.0-sources.zip?raw=true) нужен только тем, кто хочет сохранить копию проекта.

Если DeepRole уже установлен, **не удаляйте его ради обновления**: это может стереть локальную память. Сначала сохраните резервную копию, замените файлы в той папке, откуда браузер загрузил расширение, нажмите ↻ на странице расширений и обновите вкладку DeepSeek. Простая пересборка проекта не обновляет другую, ранее распакованную папку.

В этой сборке улучшены портреты и варианты ответа, восстановление истории и перенос больших миров. [Что сделано и как проверено →](../ROADMAP.md)

Личные изображения, лор и сохранения чатов в архивы репозитория не входят.
