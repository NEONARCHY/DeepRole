# RP290 — полные условия доставки и коротких ссылок

Первый RP289 результат 43/54, frozen inputs/gold/protocol/report/seal остаются неизменными. Новый результат — только **seen** regression, не новая независимая проверка. Снимки RP289 `story-obligation-recall.ts` и `game-context.ts` сохранены до изменений для проверки исходных fingerprints.

Для игрока: если в истории уже сказано, какой груз обещали доставить, где он лежит и кто разрешает вход, поддержанное «Что с тем обещанием?» подтянет эти отдельные записи вместе с новым местом приёма и оговоркой «подготовлен, но не доставлен». Короткая ссылка требует принятого уточнения в последней сцене. Вопрос вроде «Как там отправка груза?» может передать несколько проверенных кандидатов доставки; DeepRole не объявляет, что угадывает нужный предмет. Все владельцы и статусы остаются исходными. Ручного подтверждения для каждого такого подбора не требуется.

## Подтверждённая причина

`obligationRecallFacts` допускал только return-задачи. Прямые запросы о доставке получали сведения через обычный поиск, а короткие ссылки и перефразировки не получали отдельную группу условий. `obligationRecallIntent` не принимал вопросы об отправке. В английском promise-to-deliver перед названием часто стоит известное имя с possessive; его нельзя считать частью literal label.

## Контракт исправления

- Добавить доставку/ремонт к source-backed prose-title reference без изменения токенизатора, канона и исторических ролей.
- Вопрос об отправке допускает ограниченные группы кандидатов доставки, не объявляя перефразировку именем объекта. Никакого словаря конкретных сюжетов/персонажей/идентификаторов.
- Короткая ссылка требует exact quote принятой latest-turn записи. Raw recent может запретить подбор, но не доказать связь. Несколько самостоятельных названий остаются неоднозначными.
- Все записи группы должны иметь доступный source, точные quote, связанные роли и источник эпизода; старые caps16tasks/4labels/128rows и whole-context budget остаются.
- Для short-reference четыре label slots считаются после проверки принятой сцены, а не расходуются посторонними старыми задачами. Scan всё ещё максимум16 задач; для broad inquiry прежние4 labels до выбора. После scope всё ещё допустим только один effective literal bridge. Это изменение области счётчика, не увеличение размера контекста или транспортных строк.
- Сохранить прежний подбор при невозможности передать всю группу. Не обрезать условия и не считать подготовку доставкой, отмену выполнением, ремонт разрешением на разглашение.
