## Историческая публикация 2 октября и запуск на другом ПК

Репозиторий **NEONARCHY/DeepRole — приватный**. Войдите в свой GitHub, скачайте или клонируйте его. Личные миры и чаты в репозиторий не загружены: для них нужна отдельная резервная копия DeepRole со старого ПК.

Для Codex: сначала прочитать `AGENTS.md`, `ROADMAP.md` и `docs/QA-2026-10-02.md`. Не переделывать интерфейс вслепую и не считать прохождение макета проверкой личного DeepSeek.

На момент передачи: проверка типов без ошибок, 295 unit/integration и 191 E2E прошли; 21 Chrome-only сценарий ожидаемо пропущен в Firefox. На GitHub опубликован снимок рабочей папки. Старая локальная Git-история домашнего ПК не переписывалась; на рабочем ПК начинайте с нового клона ниже.

```sh
git clone https://github.com/NEONARCHY/DeepRole.git
cd DeepRole
npm ci
npm run build
npm run build:firefox
npm run typecheck
npm test
```

Нужны Node.js с npm, Git и браузер. Первая сборка создаёт `.wxt/tsconfig.json`, поэтому на свежем клоне она идёт перед проверкой типов. Chromium-тесты настроены на установленный Microsoft Edge; Firefox для Playwright устанавливается командой `npx playwright install firefox`. Графические тесты запускаются **после сборки**, без видимых окон:

```sh
npm run test:e2e -- --workers=1
```

Не запускать сборку одновременно с runtime-тестами: сборщик пересоздаёт папку расширения. Под нагрузкой параллельный запуск браузеров был нестабилен; последовательный прогон зафиксирован отдельно.

Не запускать два отдельных процесса Playwright одновременно с общим Vite-сервером: один завершает сервер, которым ещё пользуется другой. Во втором раунде такой запуск дал ошибки соединения; после последовательного запуска полный прогон прошёл. Это сбой организации проверки, не 28 найденных ошибок продукта.

## Установить готовую версию

В приватном релизе есть ссылки на Chrome/Brave и Firefox ZIP; сами архивы сохранены в папке `downloads` репозитория. Распаковать Chrome ZIP и выбрать папку с `manifest.json` через «Загрузить распакованное расширение». Для разработки можно выбрать `.output/chrome-mv3` после сборки. Firefox ZIP не подписан магазином: обычная постоянная установка не подготовлена; инструкция временной установки — в `INSTALL.md`.

Обновление файлов **не перезагружает уже работающую копию**. На странице расширений нажать обновление DeepRole, затем обновить DeepSeek. Внизу настроек видна дата сборки.
