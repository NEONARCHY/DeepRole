# UX347 — окно подключённой памяти и предупреждение о бюджете

21 октября2026. Задача пользователя по двум скриншотам.

## Изменения

- Вместо узкой колонки у индикатора — native `dialog.showModal()` в центре viewport. Лёгкая подложка40%, ширина до720px, высота до780px с адаптацией к окну. Прокручивается содержимое, заголовок и закрытие остаются видимыми. Текст записей13px вместо9px в прежней узкой панели.
- Escape/крестик закрывают окно, просмотр также закрывается по фону. Фокус возвращается на исходную кнопку. Нативный top layer удерживает окно выше перемещаемых панелей и делает фон недоступным для ввода, не переписывая стили DeepSeek.
- Формы «Запомнить» и проверки предложений остаются в том же окне. Закрытие всего окна сохраняет их смонтированные черновики; отдельная кнопка «К памяти» возвращает в список. Фон не закрывает открытую форму случайным нажатием, busy-операция защищена от закрытия.
- Причина неподвижной плашки: `GameMemoryNotice` стоял вне `WidgetDeck`; фиксированные вручную панели не участвовали с ним в общей геометрии. Полный текст заменён компактной кликабельной строкой внутри memory tile. Она перемещается и сворачивается вместе с блоком, не перекрывает другие его панели. Предупреждение остаётся доступным, даже если обычный индикатор скрыт настройкой; при сворачивании блока в dock показывается предупреждающая иконка.
- Внутри окна показан полный текст и точные числа обязательной части/локального бюджета RU/EN. Правило `required > limit`, настройки и сохранённая память не менялись. Появление предупреждения само окно не открывает.

## Почему был превышен лимит

У выбранного мира свой локальный бюджет добавки DeepRole. На пользовательском скриншоте он2000 токенов, общий подготовленный контекст около3846. Плашка означает, что обязательный лор/правила/защищённая часть уже больше бюджета; они не удаляются. Это не исчерпание серверного контекста DeepSeek. Для устранения причины нужно изменить бюджет мира или объём обязательных записей, а не просто закрыть плашку. Значения автоматически не повышались.

## Проверка и ограничения

- Ручной просмотр локального макета с настоящими компонентами в IAB/Chromium: RU при обычной ширине872px; RU/EN320×760. Заголовок/закрытие/текст/прокрутка читаемы. Снимки `benchmarks/ux347-memory-*` содержат только вымышленные данные.
- Через UI просмотрены открытие/закрытие, Escape/возврат фокуса, закрытие просмотра по фону и сохранение введённого черновика при Escape/reopen. Стрелка вправо переместила весь memory tile с x8 на x16, включая предупреждение; фоновые панели не входят в диалог.
- TypeScript и сборки Chrome/Firefox/ZIP — см. `benchmarks/ux347-verification.json`. Архивы сверены с файлами сборок и CRC.
- Новые автотесты не добавлялись, unit/E2E в этой итерации не запускались.9855 unit и8+8 браузерных из RP346 относятся к прежней версии и не выдаются за свежую проверку UX347. Личная установленная копия Edge/живой DeepSeek не проверялись и сами от сборки не обновляются. Полный Firefox UI не просматривался.
