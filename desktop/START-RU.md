# DeepRole для Windows

Распакуйте весь ZIP, например в «Загрузки», и откройте **DeepRole.exe**.

## Подключить модель

Нажмите **«Подключить модель»** в шапке. Для Venice укажите адрес `https://api.venice.ai/api/v1`, ключ Venice и ID модели `aion-labs-aion-3-5-mini`. Подойдёт и другой сервис с OpenAI Chat Completions. Подключение к модели расходует квоту или баланс выбранного сервиса.

Укажите адрес и ключ API, затем нажмите **«Загрузить список моделей»**. Выберите модель и сохраните подключение. Если сервис не выдаёт список, введите ID вручную.

В поле **«Длина и подача»** правила оформления удобно писать отдельными фразами. Например, «Реплики моноширинным шрифтом. Действия курсивом». Даже если модель ответит обычным текстом, клиент применит правило к репликам с тире в начале абзаца и к остальным абзацам прозы. Явная разметка Markdown в ответе сохраняет свой стиль.

## Перенести старый мир

В расширении откройте **Настройки → Резервные копии и защита → Экспорт → Полная резервная копия**. В клиенте откройте **Библиотека и настройки → Настройки → Резервные копии и защита** и импортируйте этот файл. Он переносит миры, портреты и историю, которую успел записать DeepRole. Полные переписки из браузера остаются на исходном сайте.

В новом чате клиента нажмите **«Продолжить из сохранённой памяти»**, проверьте фрагмент сцены и напишите следующий ход. В узком окне кнопка находится в **«Игровых панелях»**.

## Перенести приложение вместе с чатами

1. Закройте все окна DeepRole.
2. Скопируйте всю распакованную папку **DeepRole** на другой ПК. Проверьте, что внутри есть **DeepRole Data**.
3. Откройте **DeepRole.exe** из скопированной папки. История будет слева в списке чатов.
4. Введите ключ текстовой модели заново. Windows защищает сохранённый ключ средствами исходного ПК.

Храните копию папки с данными в месте, доступ к которому контролируете. Чаты клиента лежат в `DeepRole Data/Chats`.
