# RP335 — сохранённая длинная история и несколько действий

19 октября 2026. План: `RP05-PERSISTED-LONG-PLAN-20261019.md`.

## Найдено и исправлено

При двух/трёх действиях отбор RP325 не использовал фильтр доказанно пустых
повторных разговоров. На 80 повторах это давало лишние десятки строк; на 400
общий набор превышал ресурсную границу, и fallback терял часть старых условий.
В первом независимом прогоне 16 из 40 положительных query/size/locale/plot случаев
теряли хотя бы один нужный источник. Ожидания и исходный fixture не менялись.
Первый red сохранён в `.output/rp335-first.json`.

`compileRepeatContext` теперь получает объединение предметов из существующего
проверенного parser составных действий. Каждый пункт должен иметь собственное
содержательное свидетельство. Из передачи исключаются только подходящие
`isVerifiedEmptyDiscussion` строки; исходная память остаётся целиком. Все
содержательные источники и ранее выбранные непустые записи защищены. Полный
prompt должен поместиться в прежний бюджет; при нехватке, неизвестном предмете,
утрате источника/роли или выключенных функциях сохраняется прежний fallback.
Никаких новых запросов к модели, автоматического исполнения действий или
изменений guards переключения чата.

## Стенд и доказательства

- Две новые истории, три персонажа, RU/EN, 89 либо 409 отдельных фактов.
- 56 запросов: 40 положительных и 16 проверок отсутствия ложной уверенности;
  каждый в холодном, тёплом и повторно открытом индексе — 168 измерений.
- Полный text/quote/kind/task/claim/роль/source проверяется на передаваемых строках;
  вход и сохранённая база не меняются, весь prompt укладывается в 6000.
- Девять важных записей различают двух исполнителей, частичный прогресс, отзыв
  допуска, условный возврат, завершённую доставку, невыполненный осмотр, новое
  требование и мнение о владельце.
- Сначала compiler-тест сохранял только world с вручную заданными role seeds.
  Это недостаточное доказательство импортируемой истории. Runtime отверг такой
  стенд до POST; затем добавлен `story-persisted-evidence.ts`: полная историческая
  цепочка, dispatch receipts, roster из исходного текста, роли через production
  `bindStoryRoles`, checkpoint продолжения с facts/roles/episode sources/legacy effects.
  `assertStoryGraph` проверяется до записи и после чтения. Голд/исходная проза
  не менялись; у событий без говорящего больше не выдумывается speaker.
- Для 409 фактов исторический граф содержит 818 revision sources, включая
  пользовательские сообщения. Это не 409 отдельных строк IndexedDB: факты
  хранятся в общей игре мира, источники и receipts — отдельными записями.
- Промежуточный общий unit-прогон захватил старую версию harness и дал 9654 passed,
  9 failed: восемь сравнений absent roles с `{}` и итоговый счётчик. Это ошибки
  тестового представления пустых ролей; исправлены сравнением `sourceRoles ?? {}`.
  Отчёт `.output/rp335-full.json` сохранён; он не объявлен зелёным.
- Временный browser debug instrumentation удалён из итогового теста; guards и
  протокол production не изменялись. Прежние red/trace оставлены отдельно.

## Итоговая проверка

Итоговые counts/hash: `docs/benchmarks/rp335-verification.json`.
Новый набор на полноценном графе прошёл: 168 измерений, 18 fallback controls и
один запуск нового чата. TypeScript clean, Chrome/Firefox production ZIP собраны.
Окончательная installed Edge MV3 матрица без debug hooks: **16/16**, 4,1 минуты,
одним serial запуском без retries. Два новых сценария проверяют 12 actual POST
с составными действиями до/после reload: все нужные тексты, роли, статусы и
источники; сохранённый canon без изменений. Остальные 12 — прежние new-chat
fetch/XHR сценарии и два — old-chat. Это synthetic DeepSeek, не личный live-account.

Финальный общий unit на четырёх workers: 9661 passed, 3 timeout, 5 прежних todo.
28 новых тестов в нём прошли. Три timeout — 100 portions в `story-automation`,
100 turns в `story-memory-batch`, lasting recall в `story-search-current-contract`.
Они перепроверены отдельным serial запуском целых трёх файлов с прежними
таймаутами; результат отдельно в JSON. Общий параллельный run не объявляется
зелёным и не заменяется суммой прогонов. Ранее общий run на двух workers захватил
устаревший harness при его исправлении; поэтому он тоже не финальный зелёный.

## Что это не доказывает

Новая сборка ещё не установлена в личный Edge и не проверена на живой модели.
RP334 остаётся доказательством предыдущей RP333, а не этого изменения. Тесты
проверяют выборку и actual POST; качество ответа модели ими не подменяется.
Не обещаем произвольные формулировки или неограниченное количество действий:
используется существующая ограниченная грамматика и ресурсный бюджет.
При запросе о неизвестном предмете не объявляется полное покрытие.

RP-05 пока не закрыт полностью. Следующее: свежий независимый holdout длинных
повествовательных/составных ходов после этого исправления; затем при необходимости
живой повтор на новой сборке. RP-08 replay остаётся отдельным этапом.
