# «Её подарок» и «то обещание»

**Дополнение RP286:** [короткие ссылки через полную фразу обещания и вопросы о возврате](OBLIGATION-RECALL.md). Название и тема могут находиться в разных частях одной подтверждённой цитаты; новые найденные группы остаются возможными вариантами с неподтверждённой полнотой. Прежний способ для подарков ниже сохранён.

## Что изменилось

DeepRole использует явную зацепку в последней сохранённой сцене, чтобы подобрать старую память для короткого вопроса.

Например, в сцене Лида говорит: «Мой подарок — серебряный медальон. Обещание вернуть серебряный медальон остаётся в силе». Вы пишете **«Что насчёт её подарка?»** или **«Напомни, что она пообещала»**. Вместе с этой сценой в запрос могут попасть старое обещание о медальоне, его условия, сведения о хранении и выполненные или отменённые связанные поручения. Подарку не обязательно иметь отдельную задачу: явное «подарок — …» / «gift is …» тоже даёт буквальное название.

Поддержаны короткие формы «её подарок», «то обещание», несколько форм вопросов и напоминаний на русском и английском. Это ограниченный поиск по словам и сохранённым источникам. Он не понимает любые метафоры или произвольные формулировки.

## Откуда берётся уверенность

- Последняя сцена должна содержать точную цитату принятого источника текущей игровой линии. Старый фрагмент, который просто снова виден на экране, не становится новым источником.
- Название предмета должно быть явно названо в сохранённом тексте и его исходной цитате. Для задач используется существующий разбор буквального заголовка; для подарка без задачи — явная связка «подарок — название» / «gift is название».
- Проверяется вся последняя сцена. Если там второй подарок, другое обещание или неизвестный предмет в той же теме, новый путь не сужает выбор.
- У всех связанных записей должны сохраниться подтверждение источника и исторические персонажи. Удалённого персонажа нельзя заменить другим с таким же именем. Переименование при сохранённом ID поддерживается.

**Местоимение не превращается в установленную связь.** DeepSeek получает исходные цитаты, разные ID и предупреждение о неопределённости. Два обещания разных людей о предмете с одинаковым названием остаются двумя обещаниями. Название не является уникальным ID предмета. Присутствие человека рядом не доказывает, что подарок принадлежит ему.

## Если места мало или ссылка сомнительна

Добавляется весь подходящий набор вместе со всей ранее выбранной памятью. Полные цитаты, отрицания, условия и статусы задач сохраняются. Проверяется размер всего добавляемого запроса, включая обязательный лор и предупреждение.

Если полный набор не помещается, возвращается прежний подбор целиком, с прежними счётчиками. Диагностика нехватки места передаётся отдельно. На один запрос по-прежнему действует защитная граница декодера в 128 записей; это не ограничение библиотеки мира. Слова игрока не завершают задачу, не меняют владельца и не записывают новое событие сами по себе.

При отсутствии последней подтверждённой зацепки DeepRole не угадывает владельца по полу, порядку карточек или близости. Обычный подбор продолжает работать. «Беру её подарок», условные фразы, цитаты чужих вопросов и несколько разных запросов одним предложением не включают новый путь.

## Проверки и границы результата RP277

До первого изменения алгоритма закреплены 64 новых синтетических RU/EN сценария, их исходные данные, ожидаемые наборы и точный результат RP276. В каждом мире за старыми записями идут 204 более новые сцены. В этом базовом наборе прежний подбор уже покрывал все 16 положительных случаев: это проверка совместимости, **не доказательство прироста качества**. 48 защитных случаев должны сохранять прежний результат целиком.

Отдельные нагрузочные регрессии проверяют набор из 15 важных записей за этими сценами, подарок без задачи и название из одного слова. Прежний путь ограничивался восемью; новый должен передавать полный набор, сохраняя прежние выбранные источники. Эти добавленные проверки уже видны разработчику и не считаются независимым итоговым исследованием качества.

Финально прошли580 выбранных unit-проверок, включая96 новых, TypeScript и проверка diff. Четыре сценария отправки в изолированном Edge прошли; после усиления предупреждения об одинаковых названиях два новых RU/EN сценария повторены на финальной сборке:18 фактических POST,13 полных связанных записей, reload, библиотека не меняется. Chrome/Firefox и три архива пересобраны и сверены с диском. Это synthetic проверки без живого аккаунта/модели, не весь регресс. Команды, результаты и упаковка находятся в начале [CODEX-HANDOFF](../CODEX-HANDOFF.md). Старые frozen данные и первые отчёты не переписываются. Полный Git checkout нужен для повторения тестов: source ZIP не включает `tests/`.

Это **первый из четырёх запрошенных шагов RP-05**. Следующие отдельные запросы пользователя: индекс только изменившихся данных; сокращение повторной передачи неизменной памяти; новый независимый набор длинных историй. Последний нужен для общей оценки качества, включая ограничения этого поиска. RP-05 целиком пока не закрыт.
