# Готовые сборки · 0.1.0

[↓ Chrome / Brave / Edge](deeprole-0.1.0-chrome.zip?raw=true) · [↓ Firefox](deeprole-0.1.0-firefox.zip?raw=true)

Сборки от 3 октября 2026: варианты сразу окрашены мягкими цветами по типу; уточнены пояснения импорта и привязки карточек. BDS переносит текстовую память, а экспорт мира DeepRole — также готовые анкеты и портреты. Сохранены исправления длинных ответов, анализа памяти, несколько собеседников и отдельные портреты 3:4. Сначала сохраните резервную копию DeepRole. Распакуйте Chrome ZIP и загрузите папку с `manifest.json` на странице расширений. Firefox ZIP — неподписанная версия для временной установки.

[Установка и обновление](../INSTALL.md) · [Портреты и расстановка](../docs/CHARACTERS.md) · [Что исправлено и проверено](../docs/QA-2026-10-03-import-colors.md) · [Продолжить на другом ПК](../docs/CONTINUE-TOMORROW.md)

Обновление файлов не перезагружает установленное расширение. После замены сборки обновите DeepRole на странице расширений, затем вкладку DeepSeek. В настройках показывается время сборки. Новая версия в этом раунде сохранена локально; публикация на GitHub отдельно не выполнялась.

Полные исходники с тестами находятся в корне репозитория. Для разработки клонируйте репозиторий: установочные ZIP содержат только расширение, а архив `sources` создаётся без тестов и личных данных.
