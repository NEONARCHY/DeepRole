# RP324 — живой smoke новой упаковки, 19 октября 2026

Чат «Проверка памяти», существующий мир `RP319 — Чистая мастерская (тест)`.
Пользователь подтвердил обновление. Начальный видимый состав: Мира и Нора,
обе спокойны, Нора в сцене; нейтральный внеигровой статус, choices/recovery 0.
Проверка — через разрешённый браузерный UI/DOM, без network/DB interception.

## Предварительно заданный план

1. Прочитать старый набор восьми записей из source ZIP, передать его составной
   таблицей во внеигровом сообщении. Проверить шесть вопросов и неизменность UI.
2. Обычный короткий игровой ход: ответный кивок Норы, без новых вещей/обещаний.
   Проверить восстановление игрового статуса и четырёх вариантов, их не выбирать.
3. Новый независимый учебный набор (ниже): ранее не встречавшиеся имена,
   предметы и код. Он не импортируется в мир и не должен создавать персонажей.
   После ответа проверить шесть ожидаемых результатов и неизменность карточек.
4. Reload и проверка того же мира, состава, внеигрового статуса, отсутствия
   choices/recovery и пустого composer. Не закрывать исходную вкладку.

## Независимый набор: gold до отправки

Общий точный префикс каждой строки: «Все следующие передачи в учебном примере
разрешены только при двух условиях одновременно: Эйра лично согласилась и Дан
присутствует. Одно условие не заменяет другое. Зафиксировано: ».
`columns = [kind, text, task]`, `text = [0, suffix]`.

| Строка | Исходное значение | Тип / статус |
|---|---|---|
| Янтарный диск | Дан обещал передать его Эйре; дополнительно нужен тканевый чехол; ещё не передан | promise / open |
| Фиолетовая карта | Уже передана Эйре; передача завершена | event / completed |
| Белая колба | Смотритель считает её полной, никто не проверял | belief |
| Код | 7396 открывает склад, но не радиорубку | secret |
| Костяная бирка | Осталась в сейфе, Эйра её не получила; это не фиолетовая карта | secret |
| Антенна | Эйра только собирается поднять её после разрешения дежурного; ещё не поднимала | plan / open |

Контрфактическая ситуация ТОЛЬКО учебного набора: Дан присутствует, но Эйра не
согласилась. Ожидаемые ответы: (1) диск нельзя передавать — нет согласия Эйры,
нужен также чехол; (2) карта уже передана, отказ не отменяет прошлую передачу;
(3) полнота колбы не доказана; (4) код 7396 — склад, не радиорубка;
(5) бирка не получена, не путать с картой; (6) антенна только планируется,
нужно разрешение дежурного. Эти данные — не канон настоящей мастерской.

## Наблюдения

Первый старый набор: новые native UI rows 27/28, шесть ответов верны. Присутствие
Норы осталось обязательным, завершённая передача журнала не отменилась, belief
не стал фактом, код не расширил доступ, письмо не получено, футляр сохранён.
Видимые карточки/их title до и после равны; статус вне игры, choices/recovery 0.
Старый набор уже был в предыдущей переписке, поэтому сам по себе не доказывает,
что модель прочитала именно новую таблицу, а не воспользовалась старой историей.

Длинную вставку сайт сначала оформил как несохранённое .txt-вложение. Нажато
`Paste original`; перед Enter проверены 3004 символа, префикс «Вне игры:» и
новый format. Вложение не отправляли. Локальные loose probe-файлы и downloads
README отсутствуют (пользовательские удаления не отменялись); точный probe
прочитан из `downloads/deeprole-0.1.0-sources.zip`, не восстановлен на диск.

Обычный ход, rows 29/30: спокойный ответный кивок Норы, без передач/обещаний.
Мира и Нора остаются на местах; статус обновления, 4 готовых кнопки и recovery 0.
Их не нажимали. Нора теперь «Обращается к герою» — легитимное игровое изменение.
На game-снимке нижняя часть choices была под composer/краем viewport; DOM
показал 4 готовые кнопки, не только model payload. Это отдельное UX-наблюдение,
а не подтверждение удобной видимости всех четырёх. Control+End на body завершился
ошибкой locator, не повторяли вслепую и не меняли настройки интерфейса.

Свежий набор, rows 31/32: **6/6**, все предзаданные выше результаты получены.
В частности, модель прочитала именно новое условие отказа Эйры при присутствии
Дана, дополнительный тканевый чехол и новый код 7396/запрет радиорубки. Карта —
уже передана; бирка — отдельный неполученный предмет; полнота колбы — belief;
антенна — план без исполнения. Эйра/Дан не попали в карточки: сохранились ровно
две прежние Мира/Нора с теми же title, что после игрового хода. Статус вне игры,
choices/recovery 0. Длинный paste снова переключён через Paste original ДО
отправки, подтверждено 2312 символов OOC-текста, вложение не отправлялось.

Reload сохранил мир/две карточки/OOC UI/пустой composer и отсутствие вариантов.
Readback восстановленного DOM: user row 29 содержит choice_mode, не read_only;
user row 31 наоборот, format `deeprole-memory-prefix-table-v1`, 6 rows, parsed
JSON точно равен отправленному fresh packet. Это server-DOM readback, не network
interception. Для итогового снимка обычная Shift+Tab навигация показала весь
ответ над composer; исходная вкладка оставлена открытой, новых не создавали.

## Итог и пределы

Пройден живой smoke: 12/12 вопросов (6 независимых новых), игровой ход между
ними и reload. Снимки before/ooc/game/fresh/reloaded:
`docs/benchmarks/rp324-live-*-20261019.png`. Последний содержит все 6 свежих
ответов, две карточки и пустой composer.

Проверена интерпретация явно переданных составных таблиц с текстом и task.
Не доказаны автоматический выбор этих фактов из канона, auto extraction,
за-контекстная память, все сочетания metadata backward refs и полное равенство
DB/events. Их нельзя подменять этим ограниченным model smoke. Runtime не
менялся, сборки/архивы не пересоздавали, новая установка не нужна. Source ZIP
остаётся snapshot до этих doc-only заметок. Полный unit в этот live-turn не
запускали: downloads QA assets теперь отсутствуют, тесты нужно отвязать от
пользовательской очистки, не восстанавливая удалённые файлы на прежние места.
