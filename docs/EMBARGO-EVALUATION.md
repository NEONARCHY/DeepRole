# RP301 — preregistered obligation, condition and prohibition audit

## Frozen before the first compiler run

This is fresh agent-authored synthetic prose about an island research station,
not an externally blinded benchmark, live DeepSeek test or played novel.
The RU/EN stories are translations; background events repeat four templates.
No previous audit fixture, prose, query or gold is imported.

40 inputs: 24 scored recall cases, 10 uncertainty controls, 6 budget observations.
Each normal history contains 1,800 background records plus 19 authored records.
Six scale cases use 700/3,200/9,000 background records. Six budget cases use
900/3,000/6,000 tokens and are excluded from recall quality totals.
All source facts, roles and episode revisions are accepted inputs, not extraction
results. Gold requires 114 whole source records across the 24 scored cases.

## Human expectations fixed in the fixture

- North's publication needs both council signature and embargo release. Checking
  a checksum or uploading a draft is not completion or permission. Keep all four
  records: obligation, constraint, current destination and unfinished progress.
- South's completed publication is a different task and owner; select its terminal
  record and context, not its superseded open state.
- Mark's cancelled exhibition does not authorize disclosure of faces. Preserve the
  cancellation and surviving constraint, not the obsolete open task.
- A negative duty about names survives publication of a different archive.
- Revoked terminal access is ended, never an active permission.
- North's belief that signature exists remains a belief with its believer binding;
  it cannot replace verified evidence or lift the embargo. This harness checks
  transport and recall, not whether a language model obeys that distinction.
- An accepted explicit bridge licenses the short reference only to the two named
  archives. Raw unaccepted references, unknown tails, shared first names, false
  promisor and nonexistent work require a reference guard and unverified coverage.
- Free paraphrase has no accepted identity bridge: relevant source recall is wanted,
  but the uncertainty guard must remain. Real extra candidates with preserved
  roles are not automatically identity corruption.

## Procedure and integrity

Run `scripts/story-search-embargo-audit.mjs --freeze`, then `--evaluate` in a
separate process, against unchanged RP300 production. Freeze validates schema,
manual gold IDs and partitions without importing the compiler. The manifest hashes
all production TypeScript, fixture, runner, digest helper and this protocol.
Both baseline and first result/seal use exclusive creation. Never adjust gold
after seeing results. Any later fixes need a separate seen report.

Every case runs cold and warm. Check source text/quote, kind, task lifecycle,
claim, explicit roles, episode, persistent/ended status, input immutability,
cache equality, whole-record count, token metering and budget. Missing gold,
missing uncertainty guards and corrupted identity are separate outcomes.
No missing-fact case may claim complete coverage. Budget omissions are recorded
separately and are not semantic recall failures.
