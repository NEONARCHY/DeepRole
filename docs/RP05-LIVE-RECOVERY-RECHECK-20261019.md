## RP332: точный безопасный журнал вместо догадок

Добавлен локальный console warning `[DeepRole memory preparation]`, revision
`RP332`. Только статический этап, allowlisted код и ограниченное время.
Никаких draft, лора, URL, идентификаторов, произвольных ошибок, токенов или
текстов native response. Журнал не отправляется на сервер и не попадает в prompt.

- Этапы: navigation, scene/recovery/reload, activation/start/parent,
  policy/compile/vault/capture; отдельно native-snapshot и настоящий handshake timeout.
- При отказе native GET различаются HTTP, format, too-large, unreadable,
  exception, invalid shape, чужой chat/scope и ожидание ответа bridge.
- Проверки scope, active-tab, parent, lock/manual и политика fail-open/strict
  не изменены. Нет новых запросов модели, автоповторов или чтений истории.
- Отказ по-прежнему отклоняется. Непроверенный код превращается в `unknown`.

Предварительный `native-snapshot / story-review-stale` может быть исправлен
существующим единственным fresh reload. Сам по себе такой warning ещё не
означает неуспешную отправку: сопоставлять с конечным content-stage warning,
настоящим handshake timeout и видимой квитанцией отправки.

Это **диагностическое изменение**, не заявление об исправлении оставшейся причины.
