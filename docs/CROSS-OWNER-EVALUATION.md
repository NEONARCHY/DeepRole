# RP292 — независимая проверка условий и одинаковых названий

До первого запуска компилятора фиксируются новый корпус, gold, этот протокол, runner и все410src TS/TSX. Проверяется неизменённый RP291; исправлений по ходу проверки не будет. Это новый авторский synthetic accepted-memory corpus, не blind external оценка и не ответ живой модели. Старые кейсы/матчеры не импортируются fixture; общий harness/schema validation/roleSeed допустимы. Переводы, общий каркас и повторяющиеся фоновые записи коррелируют:96 запросов не равны96 независимым историям.

## Новые сценарии

Дирижабль, соляной караван и типография на RU/EN. У двух владельцев одинаковое буквальное название вещи, но разные источники, места хранения, ключи, адресаты и task keys. Передача первой вещи ещё открыта; передача второй отменена, а не выполнена. Отдельная замена детали начата, но не завершена; отдельные разрешения на перенос не разрешают раскрытие секрета.

Авторские records: a0 — обещание передать, a1 — доступ, a2 — новое место приёма вместо aOld, a3 — подготовка не доказывает передачу. b1 — место другой одноимённой вещи, b2 — отменённая задача вместо b0, b3 — отмена не получение. c0/c1/c2 — обещание заменить, условия допуска и незавершённая замена. d0/d1 — секрет и узкое разрешение без права раскрытия. latest — принятая сцена/нейтральное сообщение. Всего noise+15records; aOld/b0 запрещены в текущем наборе.

Роли задаются явными принятыми seeds: это не проверка извлечения source roles из живого ответа. Последняя принятая запись может пересказывать двух говорящих; её reporting speaker не переносится на владельцев их разных task records. Gold требует именно отдельные полные исходные записи, а не вывод по одному названию задачи.

## Gold и размеры

84 main =3сюжета×2языка×14форм,за1100background records. Девять scored семей на каждый сюжет/язык:именованная передача a0–a3,перефразировка теже4,замена c0–c2,две работы A+C,отменённая одноимённая передача b1/b2/b3,граница разрешения d0/d1,короткая ссылка A+B,свободная формулировка ссылки A+B,составное действие A+C. Для same-label ссылки нужны оба набора кандидатов: принятая сцена явно различает их,но не устанавливает единственную вещь по местоимению.

Controls:чужой обещавший,выдуманная вещь,bridge только в raw,две разные вещи,unknown raw продолжение. Gold recall им не присваивается;их нельзя превратить в положительные источники. Все ссылки/controls (42inputs) требуют unverified и reference guard. Правильные прямые запросы могут иметь осторожное предупреждение;полнота не считается доказательством семантического понимания.

Ещё6scored двухработных scale450/2300/6500records и6budget900/2400/5200 вне recall. Итого96inputs/60scored/30controls/6budget,306gold records. При малом бюджете пропуски учитываются отдельно. Scored budget16000,условия/цитаты не режутся ради зелёного.

## Порядок и метрики

`node scripts/story-search-cross-owner-audit.mjs --freeze` отдельно проверяет schema/counts/уникальность/источники/gold,пишет manifest с wx. Compiler не импортируется. `--evaluate` в другом процессе сверяет весь frozen manifest и запрещает существующие report/seal до compiler import. До/после evaluation fingerprints должны совпасть. Первый report/seal сохраняются неизменными при любом результате;ошибки становятся отдельной следующей задачей,не исправлением gold.

Проверяются missing records/case completeness,точные text/quote/kind/task/claim/source roles/revision/episode/period/persistent status,нет superseded/duplicate/fabricated records,inputs/canon/draft не меняются,cold/warm идентичны. Обязательный decoder действительного column/compact wire и полный added-context meter. Separate confidence gaps:нет guard,не unverified,false complete при missinggold. Дополнительные настоящие кандидаты не считаются смешиванием автоматически: transport fidelity измеряется отдельно от поведения модели.

Не использовать личный лор/браузер/аккаунт/API,не менятьruntime/UI/storage/settings/model/installedcopy. Старые independent reports/seals/seen reports остаются прежними. Source ZIP исключает tests;повторение требует Git checkout. После первого замера новые примеры становятся seen. RP-05/general semantic search/true delta этим audit не закрываются.
