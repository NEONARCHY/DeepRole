# Старые знания и результаты закрытых дел

Теперь предметная память может понадобиться и без открытого дела.

## Примеры

- Мира раньше сообщила: **«Код кладовой — 7319; без охраны входить нельзя»**. После многих сцен вы пишете **«Открываю кладовую»**. DeepRole может передать сохранённый код вместе с полным ограничением и источником.
- Ранее принято событие **«Мира вернула ключ Норе»**, а дело отмечено завершённым. При **«Беру ключ»** его результат может попасть в контекст. Дело останется завершённым; факт возврата не означает, что ключ теперь у вашего героя.
- В одном сообщении можно осмотреть дверь, открыть кладовую и взять ключ. Подбор дополняет сведения об открытом деле подходящими знаниями и результатами закрытых дел.

Обращаться к модели дополнительно и включать новую настройку не нужно. Ваш текст, условия, цитаты, лор и сохранённые статусы не меняются. Перезагрузка пересчитывает подбор из принятой памяти.

## Как это работает

1. Локально распознаются некоторые явные предметные фразы на русском и английском: существующие формы действий от первого лица, русские формы без «я» и небольшой набор прошедших форм вроде «открыл», «взял», `opened`, `took`.
2. Значимые слова предмета должны идти подряд в одном фрагменте текста или заголовка записи. Например, «дверь архива» не совпадает с «дверь гаража». Ключи служебных записей, значения claim и слова только из цитаты не создают предметного совпадения.
3. Для знаний требуется явно принятое длительное состояние, проверенная исходная цитата, сохранённый говорящий или носитель убеждения и связь с текущим составом персонажей. Само наличие знания не доказывает его истинность или передачу всем участникам сцены.
4. Для закрытого дела нужен сохранённый говорящий, связанный с текущим составом, и проверенный источник. Принимаются существующие статусы «завершено» и «отменено»; они не становятся открытыми и не считаются длительными знаниями.
5. Среди подходящих записей выбирается последняя по сохранённому порядку источников. Заменённый код и прежний статус уже обновлённого дела не воскрешаются. Порядок источников не означает срочность или календарную дату.
6. Сохраняются недавний контекст и уже подобранные дела. Добавляются только целые записи. Если дополнение не укладывается в общий бюджет или восемь фактов, восстанавливаются прежний подбор и его счётчики; цитаты не режутся.

## Ограничения

Это буквальный поиск, а не понимание любой формулировки. Поддерживаются ограниченные формы действий и предметы до шести слов; длинное сообщение может содержать несколько отдельных подходящих фраз. Синонимы, свободный порядок слов, местоименное «её» и неоднозначные имена не угадываются. Прочие запросы продолжают использовать обычный подбор. Условия в исходной записи сохраняются; просьба открыть дверь не доказывает разрешение или выполнение.

## Проверка

В заранее подготовленном двуязычном наборе полный целевой набор записей находится в 16 из 16 запросов вместо прежних 5. Ещё 32 случая сохраняют прежний результат при неизвестном предмете, неподтверждённом источнике, неоднозначности, другом мире и других ограничениях. Это проверка на вымышленных историях; качество ответа живой модели отдельно не подтверждено. Точные итоги общих и браузерных проверок находятся в текущем разделе [передачи работы](../CODEX-HANDOFF.md).

## English

Accepted lasting knowledge and results of completed/cancelled tasks can now supplement object memory without an open task. For example, **I opened the storeroom** can recall its recorded code and full guard-permission condition. A returned-key task stays completed; recall does not give the player possession or permission.

This is local literal retrieval using finite present/past object clauses, current frozen role IDs, exact source proof, accepted lifetimes and recorded source order. Whole ordered object terms must match one text/title fragment; quote-only terms, opaque keys and claim values cannot manufacture a match. Unknown pronouns and ambiguous identities stay unresolved. Whole additions preserve the recent anchor and previous task selection; cap8 or budget failure restores the previous result and counters. No extra model call, setting, schema change or canonical write is introduced. The fixed bilingual corpus improves complete-target recall5/16 to16/16 with32 exact controls; live-model quality remains separate.

Для «её ключ» и некоторых форм «эта дверь» добавлены отдельные [правила неразрешённых ссылок](OBJECT-REFERENCES.md): источник может помочь выбрать кандидатов, но не создаёт автоматически владельца или привязку местоимения. / See [unresolved-reference rules](OBJECT-REFERENCES.md) for guarded literal scene candidates.

Совпадающие названия независимых предметов проверяются в [длинной истории](LONG-HISTORY-CHECK.md): дополнительный приоритет не должен молча терять одну сторону. / See [long-history checks](LONG-HISTORY-CHECK.md) for complete independent candidate bundles.
