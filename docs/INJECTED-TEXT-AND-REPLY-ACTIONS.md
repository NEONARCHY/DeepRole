# RP306 — скрытый контекст и действия под ответом

## Исправление

Раньше восстановленное сообщение скрывалось только при наличии handoff/notice.
Обычные анкеты, память и правила вариантов после reload оставались видимыми.
Очистка истории удаляла не все эти блоки, и ограничение длины могло оставить
начало служебной инструкции вместо настоящего действия игрока.

`injectedUserText` распознаёт начальный служебный блок и завершённую границу
`[User message]`. Presentation показывает оставшийся текст, native DOM и запрос
DeepSeek остаются нетронутыми. Очистка истории выполняется до ограничения размера.
Повторная метка внутри текста игрока сохраняется. Незавершённый prefix не скрывается
как якобы проверенное сообщение. Для DOM assistant history используется финальный
main content, без отдельного заголовка размышлений.

Это исправление будущей подготовки истории. Уже сохранённые записи, прошлые
сжимки и чужие сообщения задним числом не переписываются.

## Действия под ответом

«Предложить варианты» теперь компактная нейтральная кнопка в строке справа от
«Создать иллюстрацию». Её host назначается в именованный slot внутри toolbar,
поэтому React не управляет чужими DOM-узлами. Связь с исходным ответом хранится
отдельно от соседства элементов. UI не меняет текст/signature ответа.

Без доступной иллюстрации кнопка работает отдельно. При выключении изображений,
замене native DOM и повторном сканировании она восстанавливается без автоматической
отправки. На узком экране кнопки переносятся. Общие neutral effects обеспечивают
одинаковые фон/текст/размер шрифта/скругление, клавиатурный фокус и disabled state.
Пояснение запроса осталось в title и aria-describedby, большая отдельная панель убрана.
