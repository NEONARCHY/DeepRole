## Отдельные диагностические повторы

- Reload: один ответ передал напоминание «Это предыдущий чат» со ссылкой на
  dd3954a5, однако не ответил по сохранённым фактам. После напоминания повтор
  вопроса опять получил предупреждение об отсутствии памяти.
- «Продолжить здесь» убрало плашку старого чата; повтор вопроса не исправил
  доставку. Новая привязка в отдельной вкладке дала тот же результат.
- Инструмент не поддерживает принудительный visible для Edge. Поэтому
  пользователь сам открыл и выбрал вкладку с этим URL и подтвердил «готово».
  В его выбранной вкладке 602384706 повторён только исходный вопрос о Норе,
  без подсказок ответа: тот же ответ без лора и то же предупреждение.

Таким образом, только неактивностью вкладки наблюдение объяснить нельзя.
Точная причина ещё не установлена. Текст предупреждения одинаков для
`context-timeout` и `context-unavailable` (`injectionWarning`); нельзя по нему
одному заявлять доказанный timeout. Успешная передача одного напоминания
также не означает успешную передачу обычной памяти.

`benchmarks/rp330-live-memory-unavailable-20261019.png`.

runtime с фактическим POST: New chat → выбор уже играемого мира → отказ от
