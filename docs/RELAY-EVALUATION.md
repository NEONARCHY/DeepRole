# RP303 — preregistered new-story audit

## Registration before compiler execution

Unchanged RP302. Fresh author-written synthetic prose in two settings: a winter
refuge accommodation pact and a regatta emergency exercise. New source text,
queries and manual gold IDs; no prior fixture/gold imports. Common schema and
integrity harness are reused. Not blind external evaluation or live model proof.
RU/EN are translations; six background sentences per setting are repeated with
unique ordinals. These are accepted facts, not extraction from played novels.

64 inputs:40 scored,16 controls,8 budget observations. Normal histories have
2200 background +19 authored records. Eight scale inputs use900/8200 backgrounds;
eight budget inputs use1000/4200tokens. Gold requires204 whole source records
across40 scored cases.24 cases require uncertainty guards and unverified coverage.
Paired translations and scale repeats are correlated, not40 independent novels.

## Manual expectations fixed before execution

1. Direct questions need all four A sources: the two prerequisites, why preparation
   does not suffice, the new place, and exactly one prerequisite satisfied while
   another remains missing. Do not infer overall permission or completion.
2. Fresh colloquial paraphrases should retrieve the same candidates while keeping
   identity uncertain. A made bed/radio noise is not fulfillment evidence.
3. New anaphoric wording has an exact accepted latest bridge distinguishing the
   two owners. Require A plus B context/terminal/comparison, without collapsing
   owners. A raw-only bridge is unaccepted and cannot establish identity.
4. First/then compound requests need A plus C1/C2/C3/C4. The original C obligation
   is cancelled, the replacement has another key and promisor and remains open.
   A cancelled old promise does not fulfill the replacement. Current source roles
   must survive; do not reinterpret original task keys as ownership transfer.
5. Completion for the similar B obligation is not permission for A. Require all
   A sources plus B3, which explicitly denies that implication.
6. An ongoing negative duty survives a separate permission. D0 and D3 stay intact.
   The historical temporary clearance is ended: require D2, never active D1.
7. Wrong promisor, nonexistent work, ambiguous first name and raw-only reference
   require a reference guard and unverified coverage; no claim of absence from
   the whole world. Real extra candidate records with original roles are not
   automatically corruption. This audit does not evaluate a model's answer.

## Procedure

Run `scripts/story-search-relay-audit.mjs --freeze` without loading the compiler.
Validate source/role/episode schemas, gold IDs, partitions and lifecycle manually
encoded in the fixture. Hash every production TS/TSX file, this protocol, the
fixture, own runner and digest utility. In a separate process run `--evaluate`.
Exclusive baseline/report/seal writes protect first results; do not change gold
or runtime after seeing a score. Any later repair is a separate SEEN iteration.

Cold/warm runs must preserve whole source text/quote, kind, claims, task keys and
statuses, explicit speaker/promisor, episode and persistent/ended status. Check
no input mutation/cache drift, superseded sources, duplicates, token metering and
budget. Missing recall, guard/status gaps and source integrity are separate.
Budget observations are excluded from recall totals; a small budget can omit
whole groups. A missing gold record paired with complete coverage is separately
flagged as false-complete. Keep first failure counts even if later repaired.
