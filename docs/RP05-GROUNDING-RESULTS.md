# RP-05 — независимая проверка поиска по источникам

## Первый независимый прогон — 17 октября 2026

Созданы два новых вымышленных сюжета на русском и английском: маяк/карта и
наводнение/паром. В каждом есть сыгранное действие, план, обещание с условием,
завершённая соседняя задача, слух с неизвестным владельцем и 48 поздних
повторяющихся обсуждений. Ожидаемые записи были зафиксированы вручную до первого
запуска. Набор не импортирует старые RP-05 gold/benchmarks. Проверялись 22 запроса:
18 с ожидаемыми фактами и 4 отрицательных/неопределённых контроля.

Результат текущего поиска памяти:

- Все ожидаемые записи найдены целиком в 15 из 18 scored-запросов; суммарно
  найдены 21 из 24 ожидаемых фактов.
- Русский: 6/9 запросов без пропусков; английский: 9/9.
- В трёх русских запросах поздние повторения вытеснили исходный план или
  условное обещание; в одном из них рядом осталась выполненная задача, но не
  нужное открытое обещание.
- Во всех четырёх контролях о слухе при неизвестном владельце подбор вместо
  source-belief записи выбрал повторяющиеся разговорные события. Это риск
  принять обсуждение/слух за установленный факт.
- В выбранных записях: 0 нарушений источника, точной цитаты, типа записи,
  атрибуции, статуса задачи или ID исходного эпизода. Бюджет и неизменность
  входных данных также проверены.

Это небольшой авторский синтетический аудит, не универсальное доказательство и
не проверка живой DeepSeek.

## Исправление и повторный прогон — RP312, 17 октября 2026

Подбор отодвигает простые повествовательные записи, которые прямо обозначают
повторное обсуждение без новых действий/сведений, только если три и более
совпадающих с запросом записи образуют повторный хвост. Одиночная запись остаётся;
старый путь прямых цитат не менялся; вопросы о разговорах/сказанных словах могут
вернуть такой пересказ. Сами факты не удаляются.

Для прямых вопросов «кто владеет?» / «кому принадлежит?» и английских аналогов
добавлен ограниченный словарный путь: требуется термин владения в запросе и
явное совпадение хотя бы одной темы предмета. Для слуха сохраняется тип `belief`;
он не становится объективной правдой.

Повторный результат:18/18 scored,24/24 ожидаемых факта,4/4 неизвестных владельца
вернули только source-backed belief, event leakage0, integrity0. Бюджет сохранён.
Полный прогон314 файлов:8673 прошло,0 ошибок,5 todo; TypeScript и
`git diff --check` чистые.
Chrome/Firefox/source ZIP пересобраны (23/23/922 entries); downloads-копии
совпадают с `.output` по SHA-256. Source ZIP содержит актуальные handoff/roadmap.

Предел остаётся: авторские синтетические сюжеты не доказывают универсальность и
не заменяют живую проверку. Следом пользователь обновит установленную копию и
проверит новый синтетический чат; затем нужен новый независимый сюжет. Личный мир
не трогать. RP-05 остаётся открыт.

Дополнительная независимая перепроверка RP312 на другом сеттинге (RP313):
[обсерватория, RU/EN](RP05-CROSSPLOT-RESULTS.md). Результат — 8/8 scored-запросов
и 10/10 целевых источников; новый runtime-код не потребовался.

Дополнительная проверка границы между повтором и новым прогрессом (RP314):
