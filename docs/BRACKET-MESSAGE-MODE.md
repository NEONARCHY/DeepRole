# Сообщения в квадратных скобках

Настройка: **Миры → Мир и профили → Изменить → [Скобки] — вне игры → Сохранить**.
Она отдельная у каждого мира. По умолчанию выключена, в том числе у старых миров.

Когда включена:

- `[Что Нора обещала?]` — вопрос вне игры. Память доступна для ответа, но события,
  отношения и характеристики сцены не меняются. Игровые варианты не предлагаются.
- `Открываю дверь. [Опиши комнату подробнее.]` — игровой ход с пояснением.
  DeepSeek получает указание не считать пояснение действием или новым фактом.
  Сама игра и обычные варианты продолжают работать.
- `Говорю: «[Открываю дверь]».` — реплика персонажа, не переключатель режима.
  Код, Markdown-ссылки и экранированные скобки тоже остаются обычным текстом.
- `Открываю дверь.` и `Что Нора обещала?` — обычные игровые сообщения.

Внешние скобки должны охватывать **весь непустой текст** сообщения. Пробелы и
переносы перед/после него допустимы, вложенные скобки поддержаны. `[]`, незакрытая
скобка или несколько отдельных вставок не включают внеигровой режим целиком.
Если привычно пишете действия персонажа в `[скобках]`, оставьте правило выключенным.
Обычные `OOC:`, `Вне игры:` и ручная отметка следующего сообщения работают как раньше.

Это настройка будущих отправок, не пересмотр старой истории. Режим отправленного
запроса фиксируется: последующее выключение правила не превращает прежний вопрос
в игровое событие. Текст сообщения сохраняется без изменений. Настройка переносится
вместе с экспортом/копией мира.
Перед отправкой расширение перечитывает сохранённое правило именно выбранного
мира. Если уведомление об изменении настройки не дошло до уже открытого чата,
это не должно превращать скобочный вопрос в игровой ход. Несохранённое изменение
в редакторе не применяется.
Правило относится только к текущему пользовательскому сообщению: скобки внутри
подключённого лора, анкет и сохранённой памяти не переопределяются как пояснения.

Для целого внеигрового сообщения защиту записей выполняет расширение, а не только
инструкция модели. Для пояснения внутри игрового хода это инструкция DeepSeek:
семантическую безошибочность самого ответа модели гарантировать нельзя.
Содержимое пояснений не вырезается из исходной истории или поискового запроса:
в нём может быть просьба вспомнить нужного персонажа или условие.

## English

Worlds → World & profiles → Edit → [Brackets] mean out of character → Save.
Opt-in, per world. A whole `[question]` is read-only OOC. A played action with
`[a note]` remains a game turn with explanatory guidance. Quotes, code and Markdown
links stay literal. Existing explicit OOC modes are unchanged; past sends are not
reclassified. Full OOC writes are blocked durably, while mixed-turn interpretation
still depends on the model following the explanatory instruction.
The convention applies only to the current original draft, never to brackets in
supplied lore, profiles or saved memory.
Before sending, DeepRole refreshes the selected world's saved convention, even
if its library-change notification was missed. Unsaved editor changes do not apply.
