# RP343 — исправление свободных ссылок и групп поручений

## Что исправлено

- Доступность исходного ответа отделена от распознанной роли автора. Отменённое поручение и его замена не исчезают из группы из-за роли unknown. Старые роли V1 не пересчитываются, владельцы не назначаются по догадке.
- При операционном вопросе без найденного буквального названия подбирается ограниченный набор ещё открытых/отменённых дел вместе с их условиями. Это запасные варианты, не доказанное понимание «холода для лекарств». Завершённый фон не вытесняет эти группы.
- Короткая ссылка может добавить названные темы последних двух реплик. Общий вопрос о готовности не сужается случайным последним предметом. Черновик и исходные записи не переписываются.
- Поддержаны предлоги внутри названия; служебный gap не становится существительным. При сравнении похожих вещей сохраняются различающие источники. Имена персонажей не становятся глаголами/словами запроса.
- Неразобранные операционные ссылки дают существующую спокойную плашку incomplete. Текст RU/EN прямо допускает другие дела среди подобранной памяти. Приветствие и обычный прежний unverified не превращаются в тревогу; модель не получает локализованную плашку, но получает оплаченный бюджетом reference guard.

Это локальный детерминированный подбор, не произвольное понимание смысла. Малый словарь предметов RP341 НЕ пополнялся предметами RP342. Непрямой запрос может получить лишние достоверные дела; модель должна сохранять неопределённость и может потребовать уточнение.
