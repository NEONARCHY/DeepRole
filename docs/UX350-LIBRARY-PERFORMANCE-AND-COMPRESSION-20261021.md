# UX350 — производительность и сжатие библиотеки

## UX350 — быстрые превью, сохранение большой библиотеки и сжатие прежних фото

21 октября 2026. Пользователь попросил ускорить библиотеку, сохранить надёжность
«Сохранить персонажа» и добавить сжатие уже загруженных картинок.

Добавлен display-only PhotoPreviewCache: миниатюры256/512/1024 создаются рядом с
оригиналами в extension context и возвращаются через отдельный readPhotoPreview RPC.
В RAM только ограниченный LRU16MiB/96 миниатюр, дедупликация одновременных запросов,
максимум2 декодирования. Это НЕ лимит числа/размера фото пользователя. Проверка
доступа/наличия оригинала выполняется и на cache hit; lock очищает кэш. Декодирование
идёт вне library lock. Full viewer/export/compression читают оригиналы. Нет новой
БД, миграции, изменения оригиналов при просмотре. Если thumbnail API недоступен,
сохраняется прежний путь загрузки. Base64 декодируется циклом без callback на байт.

PortraitLibrary монтирует только страницу9; выбор сохраняется между страницами,
«Выбрать видимые» относится к текущей странице. Map/Set вместо повторного indexOf/
includes при отрисовке. Сохранение не зависит от готовности превью. Общий
prepareCharacterSave компактирует и дедуплицирует уникальные originals перед RPC,
неизменённые image fields по-прежнему опускаются для three-way merge. PhotoAssets
также дедуплицирует повторные назначения в пределах одного compact/save. Ни BlobURL,
ни миниатюры в анкету не подставляются; транзакционный save/конфликты сохранены.

«Сжать всю библиотеку»: отдельное окно RU/EN, выбор configured WebP92% или compact
до1280px/82% (с учётом maxEdge). По одному оригиналу, без upscale, только если файл
уменьшился. Полный sheet публикуется только после успешной пачки; cancel/error не
публикуют частичный результат. Save заблокирован до окончания/отмены. Сохраняются
назначения, общие фото в selfieCategories и обе referenceKey через remap на новые
IDs; одинаковые результаты дедуплицируются. Применение к персонажу — явный Save.
Прежние unreferenced assets могут остаться в БД; уменьшение размеров выбранных
изображений НЕ обещает немедленного освобождения всей разницы на диске. Защищённые
исходники других анкет/резервных записей не удаляются. Copy настроек обновлён.

Ручной local Chromium:40 вымышленных PNG1920×1080,32223607B, отдельная IndexedDB,
реальные DeepRoleRepository/prepareCharacterSave/saveCharacter. Save во время2
preview jobs:102ms, payload1089 символов, после повторного read40 original addresses
и обе ссылки ref. Warm return:9 preview requests, originalReads18→18. Cancel сжатия
оставил неизменённые image fields (второй save1111 символов). Compact:40 фото,
30.73MiB→2.51MiB; Save48ms/payload9720, reopen40 и обе ref. Это локальный набор,
не личный мир200MB и НЕ установленный runtime-port/живой DeepSeek. RU/EN modal,
EN320 client/scroll231/231; на странице только9 articles. См. benchmarks/ux350-*
и docs/UX350-LIBRARY-PERFORMANCE-AND-COMPRESSION-20261021.md.

TypeScript и Chrome/Edge+Firefox ZIP пересобраны; CRC/source hash verification.
Unit/E2E не добавлялись и не запускались. Firefox UI/vault migration/performance
на личном мире не проверялись. Архив
downloads/DeepRole-UX350-library-performance-compression-20261021.zip; generic
Chrome/Firefox/sources обновлены. Установленную копию обновляет пользователь.
