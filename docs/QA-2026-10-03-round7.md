# Проверка синхронизации персонажей 3 октября

Показатели сцены теперь видны под крупными портретами. Исправлены сворачивание примера внутри размышлений и два сбоя вариантов при повторной генерации. Личные чаты, лор и изображения не менялись.

## Что изменилось

| Было | Теперь | Зачем |
| --- | --- | --- |
| Первым находился пример служебного блока внутри размышлений | Сворачивается только финальный блок; раздельный Markdown поддерживается | Размышления и сюжет остаются нетронутыми |
| После повторной генерации одинаковые варианты могли не вернуться | Проверяется весь ответ, даже когда номер сообщения и действия прежние | Готовый выбор снова доступен под новой версией сцены |
| Старая кнопка могла сработать после изменения сюжета с теми же действиями | Содержание ответа проверяется при нажатии | Черновик не получает устаревший ход |
| Показатели доступны только внутри анкеты | Первые два заполненных значения видны под портретом | Быстро видно состояние персонажа; все шесть доступны по нажатию |

Сохранены крупные портреты 3:4. Показатели берутся из сохранённой сцены, в порядке анкеты. Пустые и повторяющиеся значения не занимают место; «0» остаётся видимым. Числа и шкалы не придумываются. Это отражение ответа модели или ручной правки, не независимая проверка событий. Новых запросов, токенов, зависимостей и разрешений эта доработка не добавляет. Лор по-прежнему обновляется с подтверждением.

## Проверки

427 логических тестов прошли; TypeScript с поиском неиспользуемого кода — без ошибок. Покрытие выбранной области логики и хранения — 94,74% строк, не всего приложения. Полный npm audit не нашёл уязвимостей.

52 проверки персонажей и вариантов прошли в Chromium и Firefox: RU/EN, ширина 320–1280 px, показатели, пустые значения, длинный текст, полный просмотр, анкеты, портреты, клавиатура и защита черновика. Свежие нейтральные снимки просмотрены. HTML-подобные значения показателей выводятся обычным текстом, не исполняются.

Новый сценарий установленной production-сборки прошёл пять раз подряд: финальный блок рядом с размышлением и раздельным Markdown, сохранение показателей, следующий исходящий запрос, одинаковые варианты при повторной генерации, возвращение после перезагрузки и изоляция другого чата. Общие анкеты и обычные записи лора сохранились без изменений; повторно открытый ответ не применился второй раз.

До исправления два unit-теста воспроизвели сворачивание размышлений, ещё два — ошибки одинаковых вариантов. Один тест сворачивания — защитный вызов только с размышлением: обычный парсер уже игнорировал такой ответ. Сквозной тест дополнительно показал, что привязка только к безопасному контейнеру размещения недостаточна: в высоком ответе это может быть один абзац. Идентичность теперь проверяется по всему ответу, а расположение карточки остаётся отдельным решением. Ошибочное ожидание пробелов в описании для экранного диктора исправлено в тесте, не выдаётся за баг приложения.

Полный прогон: **376 браузерных сценариев прошли без ошибок**, 42 ожидаемо пропущены в Firefox — им нужен Chrome MV3. Проверены импорт, карта, память, сейф, резервные копии, переходы между чатами и перенос истории. Перенос сохраняет мир, книгу и выбранных героев, но не настройки памяти отдельного чата. Пересказ до 30 000 символов проверен; вся переписка автоматически не копируется.

Chrome/Firefox и три ZIP пересобраны. Каждый файл архивов сверён со своей сборкой или исходником по SHA-256; проверены состав, доступ только к DeepSeek и отсутствие личных данных. После упаковки прошли **9 ключевых сценариев установленного расширения** на нейтральном макете: импорт RU/EN, плавающая карта, разделённое редактирование миров, персонажи и показатели, варианты ответа и два вида переноса в новый чат.

Готовые архивы — в [downloads](../downloads/README.md). Работа сохранена локально в `codex/qa-20261003`; полный снимок с тестами — `private-assets/deeprole-checkpoint-20261003-round7.zip`. Предыдущие контрольные копии сохранены. Установочный `sources` не содержит тестов; для продолжения разработки нужен полный снимок или эта ветка.

## Живой браузер и границы проверки

В этом раунде Brave остановил управление нейтральным тестовым чатом из-за открытого интерфейса другого расширения. Встроенный браузер Codex не содержит открытых вкладок. Новых живых сообщений и сохранений памяти не было. Перезагрузка пользовательской установленной копии не подтверждена. Проверка production-расширения в отдельном профиле на макете не подменяет проверку живого аккаунта.

Настоящий Better DeepSeek и дальнейшее разделение крупных JS-файлов остаются отдельными задачами; предупреждение о размере сборки не скрывается. Новая публикация на GitHub не выполнялась.
